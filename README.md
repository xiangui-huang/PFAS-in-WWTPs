# PFAS-in-WWTPs
This Repository is used to deopsite the code for the study - Wastewater Treatment Plants as Redistribution Nodes for PFAS: Comparative Fate in Urban and Town Systems.
At present, this repository included the following sources:

1. sources code and dataset for the data comparision between PFAS in Israeli WWTPs and the global WWTPs.
2. The row dataset of PFAS in BS and DM WWTPs.
